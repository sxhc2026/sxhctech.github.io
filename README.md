> 便携式热毛巾机专业制造商 | Portable Hot Towel Machine Manufacturer

## 快速使用

直接将 `index.html` 文件上传到 GitHub 仓库即可：

### 方式一：GitHub Pages 自动发布

1. 在 GitHub 创建仓库（建议命名 `sxhctech.github.io`）
2. 上传 `index.html` 到仓库根目录
3. 进入 **Settings → Pages**
4. **Source** 选择 `main` 分支
5. 保存后等待约 10 分钟
6. 访问 `https://你的用户名.github.io` 即可看到官网

### 方式二：绑定自定义域名

1. 在 GitHub Pages 设置中填写自定义域名 `sxhctech.com`
2. 在域名 DNS 解析中添加 CNAME 记录指向 `你的用户名.github.io`
3. 等待 DNS 生效后，勾选 **Enforce HTTPS**
